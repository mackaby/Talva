# Talva Website

This repository contains the source of the **public website** for [Talva](https://talva.dev).

It is here so you can see exactly how the site is built: a server-rendered TanStack Start app, with every page's copy held as typed data so the wording stays consistent everywhere.

## What this repository is, and is not

- **It is** the marketing site: pages, content, structured data and styling.
- **It is not** Talva. Talva is a commercial platform and is **not open source**. Nothing in this repository is the platform, its API, or its infrastructure.
